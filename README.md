# 宿さがしのデータ分析（Kanazawa.R #3）

## 概要

[Kanazawa.R #3](https://kanazawar.connpass.com/event/349762/)で発表した「宿さがしのデータ分析」で紹介したプログラムです。あなたがどこかへ観光へ行くとき、日帰りでない限りはどこに宿泊するかを検討するでしょう。Rでは、その検討のために、必要な情報を地図へ可視化することができます。このプロジェクトでは、簡単な例を挙げて、その具体的な方法を紹介しています。
